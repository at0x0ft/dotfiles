## Session Management

- On start: review the latest session file in `docs/sessions/` (highest NNNN for today) and the current phase in `docs/tasks/`
- Before ending: update task checkboxes in the current tasks file and create a new session file in `docs/sessions/` with next sequence number
- On design decisions: create a new ADR file in `docs/decisions/`
- Before `/compact`: also update the current session file in `docs/sessions/`
