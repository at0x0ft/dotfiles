- **Base Version**: Powerlevel10k v1.20.15
- **Base Theme**: p10k-lean.zsh
- **Last Updated**: 2026-03-22

## Version History

  - User customizations: context/os_icon in left prompt, awesome-fontconfig mode, compact layout
- **2021-03-26**: Original monolithic config (checksum 43791, p10k-lean.zsh base)

## Architecture

Layered configuration for maintainable p10k version upgrades:

```
p10k.zsh (loader)          # Orchestrates loading, handles p10k reload
├─ p10k-base.zsh           # Generated by p10k configure (version-tracked)
└─ p10k-custom.zsh         # User overrides (preserved across upgrades)
```

### Design Principles

1. **Separation of concerns**: Base config contains upstream defaults, custom contains only your modifications
2. **Override precedence**: Custom settings automatically override base (via source order)
3. **Upgrade safety**: `p10k configure` regenerates only the base file, preserving your customizations
4. **Hot reload**: Changes to custom file take effect immediately with `source` command
5. **Version tracking**: Base file header shows which p10k version it came from

## Files

- **p10k.zsh**: Loader script that provides the anonymous function wrapper and sources both base and custom
- **p10k-base.zsh**: Base theme configuration (typeset statements from p10k-lean.zsh)
- **p10k-custom.zsh**: User customizations (only variables that differ from base)
- **instant-prompt.zsh**: Bootstrap for instant prompt (unchanged from standard p10k)

## Making Changes

### Customize Your Prompt

Edit `p10k-custom.zsh` to customize your prompt:

```bash
vim config/powerlevel10k/p10k-custom.zsh
# Add/modify typeset -g POWERLEVEL9K_* variables

# Reload in current shell
source ~/.config/zsh/hook/p10k.zsh  # (or wherever loader is placed)
```

**Example**: Add a new segment or change colors

```zsh
# In p10k-custom.zsh:
typeset -g POWERLEVEL9K_CONTEXT_FOREGROUND=220  # Change user@host color
typeset -g POWERLEVEL9K_DIR_BACKGROUND=25       # Change directory background
```

### Guidelines

- Only add variables to `p10k-custom.zsh` that **differ from base**
- Use the same `typeset -g` format as in the base file
- Group related settings with comments for clarity
- Keep customizations minimal for easier maintenance

## Upgrading Powerlevel10k

When upgrading `pkgs.zsh-powerlevel10k` in your Nix configuration, follow these steps:

### Step 1: Generate Fresh Base

Run the p10k configuration wizard with the same theme choices as before:

```bash
p10k configure

# Wizard options (original choices):
# - awesome-fontconfig + powerline
# - small icons, unicode
# - lean style
# - 24h time
# - 2 lines, dotted, no frame
# - lightest-ornaments
# - compact, many icons, concise
# - transient_prompt
# - instant_prompt=verbose

# Save as new base candidate
mv ~/.p10k.zsh config/powerlevel10k/p10k-base-NEW.zsh
```

### Step 2: Compare Changes

Review what changed in the new version:

```bash
# Compare old vs. new base
diff -u config/powerlevel10k/p10k-base.zsh \
        config/powerlevel10k/p10k-base-NEW.zsh > p10k-upgrade.diff

# Review the diff for:
# - New segments/options (adopt selectively in custom if desired)
# - Deprecated settings (remove from custom if present)
# - Breaking changes (adapt overrides in custom)
# - Changed default values (update custom if you relied on old defaults)
```

### Step 3: Update Custom Overrides

Adjust `p10k-custom.zsh` based on the diff:

- **Renamed variables**: Update variable names in custom
- **New features**: Add new options to custom if you want to configure them
- **Deprecated settings**: Remove from custom if they no longer exist
- **Changed semantics**: Adjust custom values if behavior changed

### Step 4: Replace Base

Once you've updated custom to work with the new base:

```bash
# Backup old base (for rollback if needed)
mv config/powerlevel10k/p10k-base.zsh \
   config/powerlevel10k/p10k-base-OLD.zsh

# Install new base
mv config/powerlevel10k/p10k-base-NEW.zsh \
   config/powerlevel10k/p10k-base.zsh
```

### Step 5: Test

```bash
# Apply Nix configuration
home-manager switch --flake '.#at0x0ft@work'

# Open new shell and verify:
# - Instant prompt appears quickly
# - Prompt appearance matches expectations
# - All segments work correctly
# - Custom overrides are applied

# Check a specific variable
echo $POWERLEVEL9K_MODE  # Should show your custom value
```

### Step 6: Commit (Optional but Recommended)

Track the base version in git for easy rollback:

```bash
git add config/powerlevel10k/p10k-base.zsh
git commit -m "chore(p10k): update base config to v1.XX.X"
git tag p10k-base-v1.XX.X

# Later, compare versions:
git diff p10k-base-v1.19.0..p10k-base-v1.20.0 -- config/powerlevel10k/p10k-base.zsh
```

## Identifying Current Customizations

To see what variables you've customized (useful before an upgrade):

```bash
# Extract variables from both files and compare
sed -n '/^  typeset -g POWERLEVEL9K_/p' config/powerlevel10k/p10k-base.zsh | sort > /tmp/base-vars.txt
sed -n '/^typeset -g POWERLEVEL9K_/p' config/powerlevel10k/p10k-custom.zsh | sort > /tmp/custom-vars.txt

# Show what you've customized
diff -u /tmp/base-vars.txt /tmp/custom-vars.txt
```

Or compare against the current Nix store version:

```bash
BASE_THEME=$(find /nix/store -name "p10k-lean.zsh" -path "*/powerlevel10k*/config/*" 2>/dev/null | head -1)

# Extract and compare typeset statements
sed -n '/^() {$/,/^}$/p' "$BASE_THEME" | \
  grep "^  typeset -g POWERLEVEL9K_" > /tmp/store-vars.txt

# Compare your custom with store base
diff -u /tmp/store-vars.txt /tmp/custom-vars.txt | grep "^[+]typeset"
```

## Troubleshooting

### Instant Prompt Cache Issues

If prompt doesn't update after changes:

```bash
# Clear instant prompt cache
rm ~/.cache/p10k-instant-prompt-*

# Restart shell
exec zsh
```

### Overrides Not Working

1. Check that custom file has correct syntax (no typos in variable names)
2. Verify source order in loader (base → custom)
3. Test in isolation:

```bash
# Source just the base
zsh -c 'source config/powerlevel10k/p10k-base.zsh && echo $POWERLEVEL9K_MODE'

# Source base + custom
zsh -c 'source config/powerlevel10k/p10k-base.zsh && source config/powerlevel10k/p10k-custom.zsh && echo $POWERLEVEL9K_MODE'
```

### p10k configure Overwrites Wrong File

The loader sets `POWERLEVEL9K_CONFIG_FILE` to point to base. If `p10k configure` still overwrites the wrong file:

1. Check that the loader is being sourced (not the old monolithic file)
2. Verify the path in POWERLEVEL9K_CONFIG_FILE:

```bash
echo $POWERLEVEL9K_CONFIG_FILE
# Should point to: /path/to/config/powerlevel10k/p10k-base.zsh
```

## Benefits of This Approach

1. **Clear separation**: Upstream defaults vs. user preferences are explicit
2. **Easy upgrades**: Regenerate base, review diff, update custom as needed
3. **Rollback capability**: Git tags allow reverting to previous base versions
4. **Portable customizations**: Custom file is concise and self-documenting
5. **No manual merging**: Avoid tedious line-by-line config reconciliation
6. **Future-proof**: New p10k features automatically available (opt-in via custom)
7. **Minimal maintenance**: Custom file only grows when you add new customizations
8. **Diff-friendly**: Git history shows custom changes separately from base regenerations
